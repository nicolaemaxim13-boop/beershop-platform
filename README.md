# BeerShop Admin 3.0 — прототип для тестування

На основі BeerShop 2.1. Додано редагування товарів, завантаження JPEG/PNG/WebP, попередній перегляд та імпорт Prom.ua CSV, журнал імпортів. Адмінпанель — `/manage`.

## Запуск

```bash
pip install -r requirements.txt
export BEERSHOP_ADMIN_TOKEN="$(python -c 'import secrets; print(secrets.token_urlsafe(40))')"
uvicorn app.main:app --reload
```

Відкрийте http://localhost:8000/manage. Імпортуйте CSV у вкладці «Prom.ua → BeerShop» після попереднього перегляду. Для першого запуску краще використовувати чисту базу даних.

**Увага:** У вихідному CSV є ціни у UAH та USD. USD зберігаються без автоматичної конвертації та не допускаються до оформлення замовлення, доки не буде погоджена ціна у гривнях. CSV не містить достовірних числових залишків, тому нові варіанти отримують stock=0, а значення наявності, відмінні від `+`, приховуються. Після імпорту відредагуйте залишки в адмінпанелі. Відсутні у файлі товари не видаляються. Повторний імпорт оновлює дані, тому для подальшого ручного керування не повторюйте імпорт без потреби.

## Обмеження

Не готово до production: потрібні міграції Alembic, рольова авторизація замість одного токена, аудит змін, резервні копії БД і фото, зовнішнє файлове сховище, перевірка зображень декодером, захист від зловживань, журнал платежів, тести конкурентних операцій і аудит безпеки. Папка `uploads` має бути на постійному диску, інакше фото можуть зникнути після redeploy. Система не розгорнута в інтернеті.
